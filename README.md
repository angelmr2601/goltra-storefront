# GOLTRA Storefront

Base visual de la tienda GOLTRA restaurada a la primera versión del diseño.

## Desarrollo

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Criterio de trabajo

La estética de esta versión se considera la referencia visual. Los cambios funcionales se incorporarán de forma incremental procurando no alterar la composición, jerarquía, espaciado y estilo general.

Los logos oficiales están disponibles en `public/brand`.
